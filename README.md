# Vehicle Parking App – V1 🚗

This is a **Modern Application Development I (MAD1)** project for IIT Madras. It is a full-stack multi-user web application for managing 4-wheeler parking lots. The system allows an admin to create and manage parking lots and spots, while users can book and release parking spots in real-time.

## 💡 Features

### ✅ Admin Functionalities
- Login without registration
- Create, edit, and delete parking lots
- Auto-generate parking spots for each lot
- View occupancy status of all spots
- View registered users
- View charts and summary of parking usage

### ✅ User Functionalities
- Register and login
- View available parking lots
- Auto-allocation of first available spot
- Park and release a vehicle
- View parking history and usage charts

---

## 🛠 Tech Stack

- **Frontend**: HTML, CSS, Bootstrap, Jinja2
- **Backend**: Python, Flask
- **Database**: SQLite (programmatically generated)
- **Extras**: Chart.js (for summary graphs), Flask Blueprints, Flask_SQLAlchemy
